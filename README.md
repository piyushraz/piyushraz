### 👨‍💻 About Me

I'm a Software Developer working on agentic AI systems and the modern LLM stack. My work spans GenAI chat applications, RAG pipelines, and custom agent orchestration frameworks built with LangGraph — with hands-on experience across LLM providers like watsonx.ai and Vertex AI, and emerging protocols like A2A (Agent-to-Agent) and MCP. UofT alum based in the Toronto Area.

- 🔭 Currently building: agentic frameworks for enterprise code generation & vulnerability remediation
- 🧠 Interested in: LLMs, multi-agent systems, distributed backends, developer tooling
- 🎓 HBSc — Computer Science & Geospatial Data Science, University of Toronto *(with Distinction)*
- 💬 Always happy to chat about AI infrastructure, system design, and developer tooling
